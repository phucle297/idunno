## 2026-10-10 — Include the bounded shove (3.4.1 go/no-go)

**Decision: INCLUDE.** DESIGN sanctions the optional short-range shove once network movement is reliable; the 3.3 gate and the latency matrix provide that reliability, and the prototype (`game/shove_manager.gd`, `tests/test_shove.gd`, `SHOVE_OK checks=53`) shows no fairness gap requiring deferral. Rules:

- The client sends only a request (`request_local_shove` → server); the server derives the target by the deterministic nearest rule (ties by peer id) with a 2.2m range, 60° forward cone and a real line-of-sight ray. Requests reject outside an ACTIVE match, from eliminated/airborne/controlled senders, or under cooldown. No hard player collision is introduced.
- The accepted effect is one fixed horizontal impulse (6.0) added to the victim's current horizontal velocity and clamped to 8.0: zero vertical component, no routine knockdown, no HP damage, no client-chosen direction, magnitude or target. Roof-edge and ramp-edge shoves stay grounded (no vertical launch), and pushing a moving victim clamps the result to exactly 8.0.
- Sender cooldown 2.0s; victim protection 2.5s after an accepted shove or knockdown recovery. Protection blocks only shove acceptance — disasters (`apply_damage_batch`, `apply_knockdown`) still land unchanged. A measured 0.3m+ victim movement window separates accepted shoves, and alternating attackers cannot chain-lock.
- Tested: spam (10 requests → 1 accepted), range/angle/cover boundaries (2.1 vs 2.4m, 60° vs 61°, behind, through-wall), opposing + simultaneous attackers, moving-target clamp, stairs/ramp and roof edges, death/spectator/airborne/non-ACTIVE rejects, recovery protection, disaster non-immunity, and five-rematch-style `reset_state` clearing both windows.
- 3.4.2 integration adds the distinct input, minimal ready/cooldown feedback with a readable arm/body cue, and replication of the accepted effect plus protection state with duplicate/stale suppression, then the two-client delay/jitter/loss matrix and five rematches before the milestone closes. Default: no shove while holding a prop, knocked down, dead or in menus.

## 2026-10-10 — Ship wave/cheer as bounded interruptible emotes (3.5)
